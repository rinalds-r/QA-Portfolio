# Product Page Test Cases

| ID | Title | Preconditions | Steps | Expected Result |
|----|-------|---------------|-------|-----------------|
| PDP-001 | Verify product image is displayed correctly | User is on a Product Page | 1. Open any product page.<br> 2. Observe the product image. | The product image is displayed correctly without distortion, missing elements, or broken image icons. | 
| PDP-002 | Verify image gallery works correctly | User is on a Product Page with multiple images | 1. Open a product page.<br> 2. Click each thumbnail image in the gallery. | The selected image is displayed correctly. Each thumbnail opens the corresponding product image. | 
| PDP-003 | Verify product title is displayed correctly | User is on a Product Page | 1. Open any product page. | The product title is displayed correctly and is clearly readable. | 
| PDP-004 | Verify product description is displayed correctly | User is on a Product Page | 1. Open any product page.<br> 2. Review the product description. | The product description is displayed completely and is readable without formatting issues. | 
| PDP-005 | Verify product price is displayed correctly | User is on a Product Page | 1. Open any product page.<br> 2. Review the displayed price. | The product price is displayed correctly using the expected currency and format. | 
| PDP-006 | Verify product variants can be selected | User is on a Product Page with available variants | 1. Open a product page.<br> 2. Select each available product variant (e.g., size or color). | The selected variant is applied successfully. | Product information updates correctly if applicable. | 
| PDP-007 | Verify Add to Cart button is displayed | User is on a Product Page | 1. Open any product page. | The Add to Cart button is visible, enabled, and clearly labeled. | 
| PDP-008 | Verify Add to Cart button works correctly | User is on a Product Page | 1. Open any product page.<br> 2. Click the Add to Cart button. | The selected product is added to the shopping cart successfully. The cart is updated accordingly. | 
| PDP-009 | Verify Product Page loads successfully | User is on the Product Catalog page | 1. Click any product from the catalog. | The Product Page loads successfully without errors. All essential product information is displayed correctly. |
