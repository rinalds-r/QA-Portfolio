# Test Plan

## Project Information

**Project Name:** Shopify Sauce Demo Store

**Application Under Test:**
https://sauce-demo.myshopify.com/

**Application Type:**
Demo E-commerce Website

**Testing Type:**
Manual Functional Testing

---

# Objective

The objective of this project is to verify that the main functionality of the Shopify demo store works correctly and provides a smooth user experience.

---

# Scope

The following functionality will be tested:

- Homepage
- Login
- Navigation menu
- Product catalog
- Product pages
- Search
- Shopping Cart

---

# Out of Scope

The following areas are not covered:

- Payment gateway
- Performance testing
- Load testing
- Security testing
- Mobile application
- Admin panel
- Database testing
- Source code review

---

# Test Environment

Operating System:
Windows 10

Browser:
Google Chrome (latest stable version)

Network:
Stable Internet connection

---

# Test Types

The following testing activities will be performed:

- Functional Testing
- UI Testing
- Positive Testing
- Negative Testing
